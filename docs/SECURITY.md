# Security

Security fixes target the latest release.

## Report a vulnerability

In this repository, go to **Security → Advisories → Report a vulnerability**. Include the affected version or commit, OS, Chrome version, impact, and steps to reproduce using sample data.

If private reporting is unavailable, open a GitHub issue asking for a private contact method. Keep vulnerability details and personal data out of public issues.

Report risks involving extension permissions, messages, dependencies, or unexpected access to textarea text. Use the regular bug report form for editing problems without a security impact. Test only on sites and with data you have permission to use.
